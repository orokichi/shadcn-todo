# shadcn Todo

shadcn/ui (https://github.com/shadcn-ui/ui) のデザインシステムと Lucide (https://github.com/lucide-icons/lucide) アイコンを使った Todo アプリ。

- Next.js + React + Tailwind CSS v4
- shadcn/ui コンポーネント (Button / Input / Card / Badge / Checkbox) を `components/ui` に配置、zinc ベースカラー + CSS variables
- アイコンはすべて `lucide-react`
- 機能: 追加・編集・削除、完了チェック、優先度（高/中/低）、期限、検索、フィルタ（すべて/未完了/完了）、完了済み一括削除、ダークモード、localStorage 自動保存

## 開発
```bash
npm install
npm run dev
```
